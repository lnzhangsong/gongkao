# Magic UI integration notes

- Magic UI is a React/Tailwind/shadcn-oriented component collection. This prototype is intentionally a single static HTML file, so no package dependency is added yet.
- We can reproduce the visual language safely with CSS: animated beam, shimmer button, border beam, number ticker, and subtle spotlight.
- Avoid copying external code blindly; use the library as visual inspiration until the project is converted to Vite + React + Tailwind.
