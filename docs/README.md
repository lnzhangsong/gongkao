## 一、产品定位（三句话）

1. **产品是「读本 READBOOK」**（D12）：申论只是叠加在阅读上的能力，不改名、不改整体主题。
2. **主线是「素材 × 申论写作」的有机结合**（D13）：不是做练习功能——读的时候沉淀素材，写作的时候素材直接可用，AI 负责把两头接起来。
3. **AI 不替你写文章**：只搭架子、备好料，产出一律「生成 → 人工确认 → 入库」。

## 二、整体链路

```
                517 篇人民日报时评（12 主题）+ 外部文章（P6 入库）
                                    │ 阅读
            ┌───────────────────────┼───────────────────────┐
            ▼                       ▼                       ▼
      选句即素材                读毕即拆解                金句背记
      论点/论据/金句/对策/句式   核心观点/分论点/心得       队列 + 掌握度
      （句式=原句+迁移模板）     + 范文精读（结构骨架/每段大意）
            └───────────────────────┬───────────────────────┘
                                    ▼
                                素材库（本地 IndexedDB）
              正向（题目找素材）╱        ╲ 反向（素材找题目）
                            ▼             ▼
              AI 审题 + 作答框架          AI 考点联想 / 完整出题
              （五类题型，要点挂素材卡片）  （命题角度 → 真题格式出题）
                            └──────┬──────┘
                                   ▼
                      写作参考（框架 + 配料 / 素材合集导出）
```

题目 ⇄ 素材双向可跳转；AI 的上下文是用户自己的素材库——这是读本区别于其他申论产品的核心。
