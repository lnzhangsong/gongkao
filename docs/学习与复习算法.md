## 一、底座：学习事件流（已实现）

所有算法不直接读业务操作，只读一条**只追加的事件流**：

```ts
interface LearningEvent {
  id: string            // 事件 id（upsert 幂等键，云同步用）
  objectId: string      // 作用对象：素材 id / 题目 key / 文章 id
  objectType: 'annotation' | 'exam-question' | 'article' | ...
  kind: EvidenceKind    // 证据类型（下表）
  weight: number        // 证据强度（1=弱 / 2=强）
  at: string            // ISO 时间戳——所有时间计算的依据
}
```

| 证据 kind | 触发 | 含义 |
|---|---|---|
| `tag-material` | 给文字标素材类型 | 主动加工 |
| `memorize` | 加入背记队列 | 承诺复习 |
| `mastery-self` | 掌握度自评（●○ 拨盘） | 用户自报掌握 |
| `deconstruct` | 保存文章拆解 | 篇级产出 |
| `read-finish` | 阅读进度 ≥95% | 被动完成 |
| `exam-answer` | 真题要点推导 | 题目加工 |
| `material-use` | 素材被 AI 框架采纳/导出引用 | **使用即复习**（最强巩固信号） |

**同日去重**：同对象 + 同 kind + 同一天只记一条（importEvents 与 log 同一规则）——一天重复刷同一动作不产生额外证据，防止算法被操作频率污染。

**设计取向**：不要求用户填「记住了/没记住」，一切算法从自然使用行为推导；代价是缺少二元评分，这是 §三 遗忘曲线做简化的根本原因。

## 二、复习到期队列（已实现，`reviewQueue.ts`）

**池**：金句（quote）/ 句式（pattern）且已加入背记（`memorized === true`）的素材。

**到期规则**：

| 条件 | 是否到期 |
|---|---|
| 掌握度 ≠ 2（未掌握/模糊） | 立即到期 |
| 掌握度 = 2 且无任何证据 | 到期（异常兜底） |
| 掌握度 = 2 且距最近证据 ≤ 7 天 | 未到期 |
| 掌握度 = 2 且距最近证据 > 7 天 | 重新到期 |

**排序**：未掌握在前；同组按「最近证据时间」最旧优先（最久没碰的最先复习）。

**已知边界（演进项）**：7 天是固定间隔，不随掌握次数拉长——完整间隔重复见 §五。

## 三、可提取概率 R(t)（已实现，`mastery.ts`）

回答一个问题：**这条素材现在还能被提取（写出来）的概率多大？** 取值 (0, 1]，越低越快忘。

### 3.1 公式

取 FSRS-4.5 的幂律遗忘曲线，**只取曲线、简化输入**：

```
R(t) = ( 1 + t / (9 × S) ) ^ (−2)
```

- `t`：距最近一次证据的天数（无证据的背记素材从 createdAt 起算）
- `S`：稳定性（天）——这条素材「能撑多久」的估计

### 3.2 稳定性估计

```
S = base(掌握度) × 1.3^min(使用次数, 5)

base(掌握度=0 未掌握) = 3 天
base(掌握度=1 模糊)   = 6 天
base(掌握度=2 已掌握) = 15 天
```

- **使用是最强巩固**：每被 AI 框架采纳/导出引用一次（`material-use` 事件），S 乘 1.3，最多累计 5 次（约 ×3.7，15 天掌握 → 最长约 55 天）
- 幂次封顶是刻意的：无二元评分时，使用次数的证据价值有上限，防止高频使用者曲线失真

### 3.3 为什么是简化版 FSRS（选型记录）

| 候选 | 为什么（没）选 |
|---|---|
| **FSRS 完整版**（DSR 三参数模型） | 实测最优的开源间隔重复算法，但需要逐次「对/错」二元评分历史；产品目前只有时间戳 + 自评。**取其曲线，不引入逐次评分** |
| SM-2（Anki 经典） | 需要固定间隔的卡片调度，与「使用即复习」的非定期自然提取不匹配 |
| Half-Life Regression | 需要训练数据拟合，单机场景没有 |

### 3.4 参数表（调优入口）

| 参数 | 值 | 含义 | 调整方向 |
|---|---|---|---|
| FACTOR | 9 | FSRS 衰减因子 | 越大整体遗忘越慢 |
| DECAY | 2 | 幂律指数（FSRS-4.5 默认 -2） | 越大前期遗忘越陡 |
| base(0/1/2) | 3 / 6 / 15 天 | 掌握度 → 初始稳定性 | 依据自评可信度 |
| 使用增益 | ×1.3，封顶 5 次 | 每次 material-use 的巩固强度 | 观察回声重复率 |

## 四、回声排序（已实现，`mastery.ts` echoCompare）

「使用即复习」的调度端：AI 审题/框架生成时，素材召回按 `R(t)` **升序**——可提取概率最低（快忘）的素材优先被 AI 看见、优先进入框架候选；同概率按创建时间早的优先。

**闭环**：快忘 → 先被使用 → 使用产生 `material-use` 证据 → 稳定性提高 → 从回声前排沉下去。复习不再是独立动作，而是写作过程的副产品。

## 五、文章学习状态推导（已实现，`learnerProfile.ts`）

从拆解内容推导文章状态，**用户手动设置的状态视为钉住（pinned），推导永不覆盖**：

```
未钉住 且 状态=未学 且 hasStudyContent → 建议「学习中」（其余维持 null）
```

`hasStudyContent`：核心观点、分论点、段意、结构骨架任一有实质内容（trim 后非空，分论点/段意/层次任一条即可）。

刻意只做「未学 → 学习中」的推进建议：升级到「已掌握」需要时间维度证据（见下），现有数据不支持，宁可不做。
