## 一、总目标

> **产品定位不变（决策 D12）**：产品仍叫「读本 READBOOK」，整体主题、品牌、导航命名不因申论功能而改名或重构；申论是叠加在阅读之上的能力扩展，不是独立产品。
>
> **主线是「素材 × 申论应用」有机结合（决策 D13，2026-08-29）**：核心交付是素材沉淀与申论写作之间的连接——标素材、拆文章、背金句、导出合集、素材关联写作，**不是做「申论练习」功能**；/practice 练习记录降级为后续可选（见 P5）。
>
> **行测练习是后续另一条功能线（2026-08-29）**：在申论「素材 × 写作」闭环之后，计划增加行测刷题类能力；不影响本期 P1–P4/P6/P7 的范围，产品仍叫读本。见「四、后续阶段」。

把 READBOOK 从「精读工作台」扩展出「申论大作文学习」能力，形成完整链路：

```
阅读即素材（选中即标五类：论点/论据/金句/对策/句式）→ 读毕即拆解（核心观点/分论点/心得）
→ 范文精读（结构骨架 / 每段大意 / 可迁移句式）→ 金句句式可背记（队列 + 掌握度）
→ 素材可导出（按主题/类型合集）→ 素材可写作（合集导出 + 分论点组织素材）→ 文章多来源（外部文件入库 SQLite）
```

**范文精读的定位（决策 D15）**：把「拆解」从篇级（核心观点/分论点）下沉到段级与句级——

- **结构骨架**：整篇的行文骨架（开头方式 → 主体层次 → 过渡 → 收尾），由逐段大意自动推导，也可手工调整；
- **每段大意**：逐段一句话概括（段级 summary），是骨架的原子数据；
- **可迁移句式**：从原文提炼的句式模板（原句 + 抽象化模板，如「以……之笔，绘就……画卷」），区别于金句的「原句背记」——句式回答「换一个主题我怎么写出这种句子」；
- 内容生产遵循项目总原则：**AI 生成候选 → 人工确认 → 入库**（走 AI-3 预拆解链路），也可手工填写。

原则：本地优先（localStorage / IndexedDB）、复用现有标注体系、字段向后兼容、AI 为后续增强。

## 三、分阶段实施计划

### P1 —— 素材类型标记（核心闭环）

- `src/types.ts`：+`MaterialType('thesis'|'evidence'|'quote'|'measure'|'pattern')`（D15 新增第 5 类 `pattern` = 可迁移句式）；Annotation 可选字段 `materialType? / memorized? / mastery?(0|1|2) / pattern?`（`pattern` 仅 `materialType==='pattern'` 有意义：抽象化后的句式模板字符串，原句即摘录正文）
- `src/data/material.ts`（新建）：五类常量、文案、颜色映射（论点=hl-blue / 论据=hl-violet / 金句=hl-yellow / 对策=hl-green / **句式=hl-orange**，若与现有色板冲突则在 hl-* 体系内另选）
- `annotationStore.update()` patch 联合类型扩入新字段
- 阅读页：选择工具栏加「素材」行（五按钮）；标注管理菜单加「标记为素材 ▾ / 取消素材标记」；正文渲染类型类 `mat-*` + `::after attr()` 悬停徽标（句式徽标悬停可显示模板）；移动端底部面板同步
- 摘录页：「素材类型」筛选 chip 组（含「未标记素材」）+ 类型彩色徽标

**验收**：选句一键标五类；标为句式时可填模板（可后补）；已有高亮可转素材/取消恢复原色；摘录页可按类型筛选；删摘录即删素材；刷新不丢。

### P2 —— 文章学习结构与范文精读（拆解面板）

- `src/stores/shenlunStore.ts`（新建）：persist + idbStorage，key `readbook:shenlun`；`ArticleStudy { articleId, status:'new'|'learning'|'mastered', mastery:0–3, coreThesis, subTheses[], reviewNote?, createdAt, updatedAt }`；动作 upsert/setStatus/setMastery/setCoreThesis/addSubThesis/removeSubThesis/setReviewNote/removeForArticle/importStudy/clearAll
- **范文精读字段（D15）**，并入 `ArticleStudy`：
  - `paragraphSummaries?: { paraIndex: number, summary: string }[]` —— 每段大意（一句话概括，paraIndex 对应 `content[]` 段落序号）；
  - `skeleton?: { opening?: string, bodyLayers: string[], transitions?: string[], closing?: string }` —— 结构骨架（开头方式 / 主体层次（即分论点结构）/ 过渡句 / 收尾方式）；`bodyLayers` 缺省可由 `subTheses` 映射，避免重复维护；
  - 骨架可由 `paragraphSummaries` 一键推导生成候选，再人工确认（与 AI-3 预拆解同一交互模式）。
- `ShenlunPanel.tsx`（新建）：桌面右侧抽屉 / 移动底部面板；核心观点、分论点增删改、心得、本篇素材按类型分组（点卡片 scrollIntoView 定位正文，金句可切背记）；**新增「范文精读」区：逐段大意列表（对应段落可定位/可编辑）+ 结构骨架卡片（开头/层次/过渡/收尾）+ 本篇可迁移句式分组**
- 阅读页右侧栏「申论拆解」区：状态分段控件 + 星级 + 已标记素材计数 + 打开面板；移动菜单加入口
- 文库页列表行：学习状态徽标（灰/accent/绿）+ 素材数
- 导入导出：整包顶层 +`shenlun: ArticleStudy[]`；`import.ts` 增 `isStudyShape`，按 articleId 合并；设置页接线 + 文案

**验收**：每篇可记状态/星级/核心观点/分论点/心得；**可逐段记大意并定位到段落；结构骨架可手工编辑或由段意一键推导；本篇句式卡片可定位原句并显示模板**；卡片定位正文正确；整包含学习记录可跨设备迁移。

### P3 —— 金句背记与素材导出

- 摘录页 + 拆解面板：金句 ★ 背记开关、掌握度点（0/1/2）直接可点；**句式（pattern）同金句一样支持背记开关与掌握度**（背模板而非原句）
- 「待背记金句/句式」快速筛选（memorized === true）
- `materialExport.ts`（新建）：按当前筛选导出 Markdown 合集（固定顺序 论点→论据→金句→对策→句式，按主题分组；句式条目带「原句 → 模板」两行）+ JSON（沿用摘录格式）
- 可选子任务：复习翻转卡 ReviewModal（正面金句 → 来源文章 → 标模糊/掌握）

**验收**：金句/句式可背记可筛选；导出的 Markdown 合集（含句式模板）可直接当写作参考。

### P6 —— 外部文章引入管线

- `scripts/import-*.{mjs,ts}`：按用户提供的文件格式写解析器（docx / txt / md / html 按需适配），直接写入 `data/articles.db`（SQLite，字段对齐现有 schema：title/author/content[]/source/topic/date/pullquote）

- 保持 API 只读分发不变（Vercel Function `/api/articles`）

**验收**：给一个样例文件 → 解析入库 → 前端文库可搜到、可读、可标素材。

#### P6+ 站外找文：主流媒体文章搜索与导入（2026-09-02 提案，未实施）

> 动机：AI-4 反向出题闭环（2026-09-02 已上线）跑通后，素材来源仍限于已入库的 517 篇。申论备考的核心媒体是人民日报及同类官媒，需要一个「站外找文 → 回流入库」的顺手续环，让「读文章 → 出题」的原料可持续供给。

**功能形态（两段式，可分期交付）：**

1. **站外搜索直达（轻，先做）**：文库页 / 管理页提供「站外找文」入口——输入关键词，一键在新标签页打开主流媒体站内搜索：
   - 人民日报：`http://search.people.cn/s?keyword=<关键词>`（人民网站内搜索，可按时间/版面过滤）
   - 备选源：新华网（so.news.cn）、光明网（search.gmw.cn）、求是网；求实补充，按申论相关性取舍
   - 零后端、零解析维护成本；用户在源站浏览，复制文章链接

2. **链接回流入库（重，后做）**：管理页「从链接导入」——粘贴一篇人民网文章 URL，走 Vercel Function（如 `/api/fetch-article`）服务端抓取页面并解析出 title / author / date / content[]，预览确认后走既有入库路径写入 `data/articles.db`；主题（12 类）与 pullquote 由人工选定或 AI 建议候选
   - 解析器按站点写：人民网文章页结构相对稳定，先只做人民网，其他站点按需加（遵循 D11：一次一个格式）
   - 抓取需带 UA 与超时兜底；失败时降级为手动粘贴正文导入（现有 AdminEditPage 已支持手工录入）

**边界与风险：**

- 仅做**个人学习用途的轻量抓取**，不做批量爬取、不做全文镜像分发；遵守源站 robots 与访问频率克制（单篇、用户主动触发）
- 站点改版会导致解析器失效——解析失败必须给出清晰错误与「转手动录入」的出口，不做静默错数据
- 搜索直达（第 1 步）不涉及任何抓取，无合规风险，可先行上线

**验收（第 1 步）**：文库页输入关键词 → 新标签打开人民日报站内搜索且关键词已带上。
**验收（第 2 步）**：粘贴一篇人民网文章 URL → 解析预览 → 确认入库 → 文库可搜可读可标素材，AI-4 考点联想直接可用。

## 七、继承的决策点与新决策点

| # | 决策点 | 结论 |
|---|---|---|
| D1–D8 | 沿用设计方案结论（素材=摘录同生命周期；不做自填卡片；面板=抽屉；状态+星级并存；复习卡 P3 可选；不设 /materials；真题规范词后置。其中「固定 4 类」已被 D15 修订为 5 类） | D15 修订后不变 |

| D13 | 申论练习是否为核心功能 | **否，主线是「素材 × 申论写作」的有机结合**：核心是素材沉淀（标四类/拆解/背记）与写作应用（分论点组织、素材合集导出、素材关联写作）的连接；/practice 练习记录整体后置为后续可选，仅在素材闭环后仍需要时再做 |
