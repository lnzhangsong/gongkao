## 一、总目标

把 READBOOK 从「精读工作台」升级为「申论大作文学习工具」，形成完整链路：

```
阅读即素材（选中即标四类）→ 读毕即拆解（核心观点/分论点/心得）
→ 金句可背记（队列 + 掌握度）→ 素材可导出（按主题/类型合集）
→ 练习有记录（/practice 题目 + 提纲 + 关联素材）→ 文章多来源（外部文件入库 SQLite）
```

原则：本地优先（localStorage / IndexedDB）、复用现有标注体系、字段向后兼容、AI 为后续增强。

## 三、分阶段实施计划

### P1 —— 素材类型标记（核心闭环）

- `src/types.ts`：+`MaterialType('thesis'|'evidence'|'quote'|'measure')`；Annotation 可选字段 `materialType? / memorized? / mastery?(0|1|2)`
- `src/data/material.ts`（新建）：四类常量、文案、颜色映射（论点=hl-blue / 论据=hl-violet / 金句=hl-yellow / 对策=hl-green）
- `annotationStore.update()` patch 联合类型扩入三个新字段
- 阅读页：选择工具栏加「素材」行（四按钮）；标注管理菜单加「标记为素材 ▾ / 取消素材标记」；正文渲染类型类 `mat-*` + `::after attr()` 悬停徽标（不破坏偏移）；移动端底部面板同步
- 摘录页：「素材类型」筛选 chip 组（含「未标记素材」）+ 类型彩色徽标

**验收**：选句一键标四类；已有高亮可转素材/取消恢复原色；摘录页可按类型筛选；删摘录即删素材；刷新不丢。

### P2 —— 文章学习结构（拆解面板）

- `src/stores/shenlunStore.ts`（新建）：persist + idbStorage，key `readbook:shenlun`；`ArticleStudy { articleId, status:'new'|'learning'|'mastered', mastery:0–3, coreThesis, subTheses[], reviewNote?, createdAt, updatedAt }`；动作 upsert/setStatus/setMastery/setCoreThesis/addSubThesis/removeSubThesis/setReviewNote/removeForArticle/importStudy/clearAll
- `ShenlunPanel.tsx`（新建）：桌面右侧抽屉 / 移动底部面板；核心观点、分论点增删改、心得、本篇素材按类型分组（点卡片 scrollIntoView 定位正文，金句可切背记）
- 阅读页右侧栏「申论拆解」区：状态分段控件 + 星级 + 已标记素材计数 + 打开面板；移动菜单加入口
- 文库页列表行：学习状态徽标（灰/accent/绿）+ 素材数
- 导入导出：整包顶层 +`shenlun: ArticleStudy[]`；`import.ts` 增 `isStudyShape`，按 articleId 合并；设置页接线 + 文案

**验收**：每篇可记状态/星级/核心观点/分论点/心得；卡片定位正文正确；整包含学习记录可跨设备迁移。

### P3 —— 金句背记与素材导出

- 摘录页 + 拆解面板：金句 ★ 背记开关、掌握度点（0/1/2）直接可点
- 「待背记金句」快速筛选（memorized === true）
- `materialExport.ts`（新建）：按当前筛选导出 Markdown 合集（固定顺序 论点→论据→金句→对策，按主题分组）+ JSON（沿用摘录格式）
- 可选子任务：复习翻转卡 ReviewModal（正面金句 → 来源文章 → 标模糊/掌握）

**验收**：金句可背记可筛选；导出的 Markdown 合集可直接当写作参考。

### P4 —— 打磨与回归

- e2e-smoke.mjs 扩展：素材标记、类型筛选、学习状态持久化、导入导出
- 夜读主题下素材色半透明；旧数据兼容回归（无新字段的旧摘录 = 未标记素材）
- 首页：继续阅读主卡学习状态小徽标；可选统计行「已拆解 X 篇 · 素材 Y 条」
- `npm run build` 通过 + 冒烟全绿

### P5 —— 申论练习记录（/practice，新路由）

- `src/stores/practiceStore.ts`（新建）：idbStorage，key `readbook:practice`
  - `PracticeRecord { id, question, questionType?('概括'|'分析'|'对策'|'应用文'|'大作文'), topic(12 主题), wordLimit?, sourceMaterialIds?(关联素材/文章), outline:string[](分论点提纲), myAnswer?, date, createdAt, updatedAt }`
- `PracticePage.tsx`（新建 `/practice`）：录入表单 + 记录列表（按主题/时间浏览、展开详情、编辑/删除）
- 练习详情内展示该主题下的素材卡片（过滤 annotationStore），供写作时引用
- Nav 增「练习」入口；首页增入口卡

**验收**：录一条大作文练习（题干+12 主题+提纲）→ 列表可见可编辑 → 能看到同主题素材卡片；刷新不丢。

### P6 —— 外部文章引入管线

- `scripts/import-*.{mjs,ts}`：按用户提供的文件格式写解析器（docx / txt / md / html 按需适配），直接写入 `data/articles.db`（SQLite，字段对齐现有 schema：title/author/content[]/source/topic/date/pullquote）
- 入库后自动获得统一能力：阅读、素材标记、拆解、练习关联
- 保持 API 只读分发不变（Vercel Function `/api/articles`）

**验收**：给一个样例文件 → 解析入库 → 前端文库可搜到、可读、可标素材。

### P7 —— 导航与入口收尾

- Nav 最终形态确认（READ / ARCHIVE / NOTES / PRACTICE / SETTINGS，「学习」是否独立页见 D10）
- 首页聚合入口：继续阅读（带学习状态）、去练习、待背记金句提醒（可选）
