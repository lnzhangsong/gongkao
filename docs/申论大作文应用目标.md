## 背景
现有 517 篇人民日报时评（12 主题分类）是优质申论素材。
目标：把文章库变成「申论大作文素材库 + 学习工具」，AI 辅助后续再接入。

## 二、文章学习（结构化拆解 + 拓展）
- [ ] 每篇文章的**学习视图**：
  - 论点是什么（核心观点 / 分论点）
  - 理论论据有哪些（政策依据 / 理论支撑）
  - 金句都有哪些（可背记的句子）
  - 对策有哪些（可借鉴的措施）
- [ ] **拓展延伸**：由一篇文章联想/关联——
  - 同主题的其他文章
  - 相关素材卡片
  - 可能的申论考点 / 命题角度
- [ ] 学习状态标记：未学 / 学习中 / 已掌握（掌握度）
- [ ] 金句背记：标记需要背记的金句，配合记忆卡片复习
