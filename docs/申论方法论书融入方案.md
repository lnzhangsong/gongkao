# 申论方法论书融入方案 ——《申论写作八讲》（/method）

> 状态：**已落地**（2026-09-15）。本文是《申论方法论与答案溯源设计方案.md》M-2 决策（「通用方法论若需回归，走独立文档/页」）的兑现：整本书作为独立内容线上线，不向真题页 / AI 页塞静态卡——静态方法论卡曾在 M1 做过又废弃（「静态内容重复、脱离题目」），本方案是其回归路径，形态为**独立阅读线 + 按需供给 AI**。

## 一、内容与定位

- **书**：《申论写作八讲》（半月谈教育 编著，2022-01）。主题是「练人」而非「练题」：审题与读材料（第二讲）、四项基本训练——删减/替换/仿写/改写（第三讲）、五大题型答题策略（第四~八讲，含 11 张「模型」图）、大作文写作技巧与写作积木（第八讲）。
- **定位**：申论线的「方法底座」。阅读侧（素材精读）、练习侧（真题溯源 /exams）、AI 侧（/assist）都是「做题时用」，这本书补「做题前学方法」的位置。
- **边界（与既有裁定对齐）**：
  - 不做批改打分 / 段落升格（A1/A2）——第三讲的仿写/改写只作为**书中方法论阅读**，不做成站内互动练习；
  - AI 只「教方法 + 针对题目推导」，不代写（A3）；
  - 不进真题解析面板塞静态卡（M1 修订记录）。

## 二、数据链路（站内静态内容的 A 范式）

```
EPUB（本地文档目录，不进仓库）
  → scripts/parse-shenlun-book.py          解析：讲→节→目 三级、目为渲染单元；jpg→webp
  → data/shenlun-book/book.json + images/  （仓库内可读源；60 图约 1.6MB）
  → scripts/import-shenlun-book.mjs        入库 articles.db：shenlun_book（meta）+ shenlun_book_units（单元）
  → api/data.ts GET /api/shenlun-book      （整书一次返回 ~500KB，边缘缓存 1h；vercel.json 加 rewrite，本地 api-server 转发）
  → src/lib/api.ts fetchShenlunBook()      （会话缓存）
  → src/pages/MethodPage.tsx               （/method 路由，Nav「METHOD」入口）
```

- **单元（unit）模型**：`{ id:"l{讲}-u{序}", lecture, idx, level(1讲导语/2节/3目), title, kind("summary"=各节小结), blocks[] }`；blocks 四种内容块：`p` 正文 / `sig` 例文标题行 / `center` 例文文章题 / `img` 书内扫描图（`role`: model 模型图 / answer 参考答案·对比 / essay 例文 / figure 其他）。扫描图是核心内容（模型图、参考答案、答案对比分析都在图里），必须随文展示。
- **图片**：`src/data/bookImages.ts` 用 `import.meta.glob` 把 `data/shenlun-book/images/*.webp` 打进构建产物（同行测题图模式），`<img loading="lazy">` 按需加载。
- **重建链登记**：`rebuild-db.mjs` STEPS、`ensure-db.mjs` REQUIRED_TABLES、`dbSource.test.ts` 重建等价性表清单均已加入新表。
- **重跑解析**：换书/改结构时 `python3 scripts/parse-shenlun-book.py --epub <路径> && vp run db:rebuild`（默认 EPUB 路径为本机 Downloads，源不进 git）。

## 三、页面（/method）

- **结构**：页头（书名/版本/进度 + 封面）→ **按「页」阅读，一页 = 讲内一个顶级小节**（节/独立目/讲导读，`chunkPages` 切分：节下的目并入该节页，独立目各自成页，整页小结独立成页）——整讲仍太长（第二讲 25 目），页间「上一页/下一页」跨讲连续翻，末页位为全书结语。版心同 `reading-layout`（900+280 居中，1600/2400px+ 宽屏断点同样加宽）。**右栏整体粘性**：上半是讲次导航（前言+八讲、讲内进度 x/y、当前讲高亮并展开其页列表，点击切讲/切页），下半是阅读辅助面板；顶部不放导航——宽屏下横排讲次条会拉得过开（用户实测否掉）。页头 kicker 行承载讲次上下文（LECTURE 四 · 第四讲 …），h2 为页题。
- **正文渲染与人民日报文章一致**：正文容器挂阅读页 `article-body` 类 + `--reader-*` 内联变量（同真题详情页做法），字体/字号/行高跟随阅读设置、段首缩进受设置开关控制；**右栏复用 `ReaderToolsPanel`（阅读辅助菜单）**——字号/正文字体/阅读主题/规范词框/段落聚焦全部可用（段落聚焦经 `useFocusMode` 新增的 selector 参数匹配嵌套段落）。书页特有块保留——模型图白底书页框、小结淡染卡（● 条目列表节奏 + 细分隔线）、参考答案/对比/要求段轻量标签、
  **原文引用句**（被页内更长段落包含的段落 → 左线引用块，`quoteTexts` 包含检测）、
  **列表行**（选项/序号/● 等短行 292 处 → 1.8 行高紧凑节奏、缩进随正文）、
  **碎片短段组**（连续 ≥3 个短段打包 `.method-run`，不吃 29px 段距）。
- **定位与深链**：页锚点写 hash（页 id = 页首单元 id，如 `#l04-u04`；兼容 `#lec-l04`，`history.replaceState` 不产生历史记录，刷新保持位置），深链直达某页（单元深链会解析到所属页）；锚点滚动一律 `behavior: 'instant'` 瞬跳（全站 smooth 平滑飞行在长内容上光栅跟不上）。
- **学习进度**：每「目」一个已读圈钮（`methodStudyStore`，IndexedDB `readbook:method-study`，键形校验 + 坏记录拒入）；讲/全书进度 = 已读/总目数。**导语（level 1）不计入进度**。仅本地，不进云同步、不进学习事件流——读书记录是否接入复习排期，等复习算法侧有结论再定。
- **移动端**：讲次条横向滑动（本身即粘顶），正文单栏，阅读辅助面板退到正文之后。
- **退出登录**：`authStore.clearLocalData()` 已纳入清空。

## 四、与 AI 线的连接（方法卡注入）

`src/lib/methodDigest.ts`：从各讲小结提炼的**题型方法卡**（通用审题读材料卡 + 概括/分析/对策/应用文/大作文五张，保留原书术语与讲次出处，共约 2KB）。`aiAssist.ts` 的 `draftFramework`（审题立意 + 作答框架）在 prompt 里注入「方法论参考」块——AI 的推导贴合本书方法，与题目/材料冲突时以题目为准。A4 边界内：直接拼 prompt，不做检索。`aiExamTrace`（真题溯源）暂不注入：该链路已有既定字段规格与调优基线，避免一次改动扰两个 prompt。

## 五、后续（按需）

- **大作文辅助四环节**（优化清单 🟠）：本书第八讲（立意/标题/开头/过渡衔接/分论点/积木/结尾）可直接充当「立意、衔接」两环节的知识供给；与素材库（素材环节）、规范词库（规范环节）拼成完整工作台草案。
- **方法卡扩展**：`aiExamTrace` / 反向出题（aiExamGen）按需注入对应讲方法。

- **思考题**：书中 24 道思考题暂按正文展示；若做自答留存，另立数据模型（对齐 A3：用户内容 AI 不覆盖）。
