## 一、背景与目标

现有 517 篇人民日报评论年编（12 主题）是优质申论素材，但阅读与素材沉淀之间缺少「申论化」的一步：

- 读到的**论点 / 论据 / 金句 / 对策**没有类型标记，之后无法按类型检索与复用；
- 每篇文章的**结构拆解**（核心观点、分论点）没有落点，读完即散；
- 金句**背记**没有队列，素材**导出**没有按主题的合集形态。

本方案的目标是：**让「阅读」这一动作直接产出申论素材与学习记录**——选句即素材、读毕即拆解、金句可背记、素材可导出，全部本地化（IndexedDB），不引入 AI（AI 拆解留作后续阶段）。

### 1.1 素材基础盘点（读源现状）

按用户提供资料（`~/Documents/人民时评/`）盘点与本方案相关的三类素材：

**① 人民日报评论年编 2025（已入库）**
- 文件：人民时评 / 人民论坛 / 人民观点 / 评论员观察 4 个 docx + 加水印 pdf
- 现状：已解析入库 `data/articles.db`（517 篇：人民时评 191 / 人民论坛 128 / 人民观点 20 / 评论员观察 175），阅读页可读全文
- 文章结构（与 docx 原文核对）：标题 → 作者 → **导语金句**（加粗短句，如“在法治引领下，推动阅读服务从‘有形覆盖’转向‘有效覆盖’……”）→ 正文段落 → 刊发日期
- 对拆解的意义：
  - **导语 = 天然「金句」候选**（DB 已有 `pullquote` 字段，可在拆解面板一键入素材）；
  - 部分文章自带**分论点小标题**（如《冰雪经济中的发展之道》：供需匹配 / 以旧生新 / 点面联动 / 补位赋能），是「分论点」拆解的直接落点（Phase 2 可做小标题识别预填）；
  - 论点 / 论据 / 对策均以原文句子形式出现，适合「选中即素材」交互。

**② 国考申论真题 2000–2025（未入库，未来素材）**
- 位置：`【01】国考真题资料/国考2000-2026真题pdf 【推荐用这个版本】/2000-2025国考申论PDF/`（另有赠送 word 版）
- 结构（以 2025 地市级核对）：
  - 【给定资料】材料 1–N（案例叙述体：宣化葡萄园、虑远科技治水、林票制改革、元科普论坛等）
  - 【作答要求】五类题型：概括题（≤200 字）/ 分析题（≤300 字）/ 对策·建议题（≤450 字）/ 应用文·提案（≤500 字）/ 大作文（1000–1200 字）
- 对方案的意义：若后续做「真题阅读模式」，需解析 PDF → 结构化「题干 + 材料 + 参考答案」，复用本方案的素材标记与拆解；本期不实现（见 §三）。

**③ 申论规范词（未入库，增强素材）**
- 位置：`【01】国考真题资料/2026申论规范词合集/`（1070 词、110 句规范表达、行政执法 268 例等 6 份 pdf）
- 结构：按「具体表现 → 规范词」映射，分类为 基层 / 科技 / 社会 / 文化 / 生态 / 经济 / 法律 + 造成原因 + 解决对策（例：“旅游＋茶叶＋文化体验——产业融合”“针对需求开展培训——针对性培训”）
- 对方案的意义：可作为「对策 / 论据」素材卡片的**规范表达增强**（标记素材时联想规范词），或独立规范词库；属 AI 辅助类后续功能，本期不实现。

## 二、设计原则

1. **复用现有标注体系，不另起炉灶**。素材卡片 = 带「素材类型」的摘录（Annotation），直接复用偏移定位（src/lib/offsets.ts）、正文渲染（splitParagraph）、摘录页分组、导入导出管线。
2. **两类内容分开建模**：摘录型素材（绑定原文偏移）留在 Annotation；文章级分析字段（核心观点/分论点/心得/学习状态）进独立 store，避免破坏 Annotation「必有 start/end」的不变式。
3. **字段全部可选，向后兼容**。旧数据无 materialType / 新 store 为空，均可正常运行，无需数据迁移脚本。
4. **不新增路由（v1）**。素材库 = 摘录页（/notes）加筛选维度；学习结构 = 阅读页内抽屉；导航保持 READ / ARCHIVE / NOTES / SETTINGS 四项。
5. **分四阶段交付**，每阶段有独立验收标准，可单独上线。

## 四、核心概念

### 4.1 素材卡片 = 带素材类型的摘录

选中正文 → 弹出工具栏 → 点「金句」→ 生成一条 Annotation：

- 素材卡片**必须有原文偏移**（start/end），是正文摘录的「申论化标签」；
- 视觉：四类素材用四种高亮色区分（复用现有 hl-* 色板，夜读主题自动半透明）；
- 删除摘录 = 删除素材卡片（语义一致：卡片即摘录）。

### 4.2 文章学习结构（ArticleStudy）

非摘录内容，按文章存储的分析字段：学习状态（未学/学习中/已掌握）、掌握度（1–3 星）、核心观点、分论点列表、学习心得。

### 4.3 素材类型定义（2026-08-30 起为 5 类，决策 D15）

| 类型 | key | 语义 | 默认色（复用 hl-*） | 说明 |
|---|---|---|---|---|
| 论点 | thesis | 核心观点 / 分论点 | 冷蓝 hl-blue | 文章主张、段旨句 |
| 论据·理论 | evidence | 政策依据 / 理论支撑 | 柔紫 hl-violet | 引用的政策、理论、数据 |
| 金句 | quote | 可背记的句子 | 暖黄 hl-yellow | 支持背记标记 |
| 对策 | measure | 可借鉴的措施 | 松绿 hl-green | 做法、机制、路径 |
| 句式 | pattern | 可迁移句式模板 | 橙 hl-orange（或色板内另选） | 范文精读用：原句即摘录正文，`pattern` 字段存抽象化模板；支持背记 |

## 五、数据模型设计

### 5.1 Annotation 扩展（src/types.ts）

    /** 素材类型：论点 / 论据·理论 / 金句 / 对策 / 句式（D15） */
    export type MaterialType = 'thesis' | 'evidence' | 'quote' | 'measure' | 'pattern'

    export interface Annotation {
      // ……现有字段（id/articleId/kind/text/start/end/createdAt/color/underlineStyle/noteText/tags）
      /** 申论素材类型标记（无 = 普通摘录） */
      materialType?: MaterialType
      /** 背记：加入背记队列（quote 与 pattern 有意义，D15） */
      memorized?: boolean
      /** 背记掌握度：0 未掌握 / 1 模糊 / 2 已掌握 */
      mastery?: 0 | 1 | 2
      /** 可迁移句式模板（仅 materialType === 'pattern' 有意义）：抽象化后的句式，如「以……之笔，绘就……画卷」 */
      pattern?: string
    }

- 常量与文案：src/data/material.ts（新建）导出 MATERIAL_TYPES、MATERIAL_TYPE_LABELS、MATERIAL_TYPE_COLORS（映射到 hl-* 类）、类型徽标文案。
- annotationStore.update() 的 patch 联合类型扩入 materialType | memorized | mastery；其余（add/remove/import）无需改动。
- **不迁移**：字段可选，旧摘录自动视为「未标记素材」。

### 5.2 新 store：shenlunStore（src/stores/shenlunStore.ts 新建）

    /** 学习状态：未学 / 学习中 / 已掌握 */
    export type StudyStatus = 'new' | 'learning' | 'mastered'

    export interface ArticleStudy {
      articleId: string
      status: StudyStatus          // 默认 'new'
      mastery: 0 | 1 | 2 | 3       // 掌握度 1–3 星，0 = 未评估
      coreThesis: string           // 核心观点（自填）
      subTheses: string[]          // 分论点
      reviewNote?: string          // 学习心得 / 复盘
      // —— 范文精读（2026-08-30 新增，决策 D15，字段可选、向后兼容）——
      paragraphSummaries?: { paraIndex: number; summary: string }[]
                                   // 每段大意，paraIndex 对应 content[] 段落序号
      skeleton?: {                 // 结构骨架
        opening?: string           // 开头方式
        bodyLayers?: string[]      // 主体层次（缺省可映射 subTheses）
        transitions?: string[]     // 过渡句
        closing?: string           // 收尾方式
      }
      createdAt: string
      updatedAt: string
    }

- 持久化：zustand persist + idbStorage，key readbook:shenlun，结构 { study: Record<string, ArticleStudy> }（partialize 只存 study）。
- 动作：getStudy(id)、upsert(patch)（按字段更新）、setStatus/setMastery/setCoreThesis/addSubThesis/removeSubThesis/setReviewNote、removeForArticle(id)、importStudy(list)、clearAll。
- 统计辅助：某文素材卡片数由页面层 useMemo 过滤 annotationStore 计算，不落 store。

## 六、交互与界面设计

### 6.1 阅读页（/reading/:articleId）

#### ① 选择弹出工具栏：新增「素材」行

现有工具栏结构（hl-dots 色点行、ul-dots 样式行、高亮/下划线/笔记按钮）下新增第四行：

    ┌───────────────────────────────────┐
    │ ● ● ● ● ●   ─ ─ ─ ─              │   ← 高亮色点 / 下划线样式（现有）
    │ [高亮] [下划线] [笔记]              │   ← 现有按钮
    │ ───────────────────────────────── │
    │ 素材： [论点] [论据·理论] [金句] [对策] [句式] │   ← 新增行（句式为 D15 新增）
    └───────────────────────────────────┘

- 点击任一类型 → 生成该段摘录的素材卡片：
  - 类型为 highlight，color = 该类型默认色，materialType = 点击类型；
  - 与现有高亮「重叠合并区间」逻辑一致（applyMark 复用，加 materialType 参数）；
  - 生成后立即弹出标注管理菜单（与现有高亮行为一致，可在其中改色/加笔记/删除）。
- 移动端底部面板（≤500px）同样增加素材行。

#### ② 正文素材渲染：类型色 + 悬停徽标

- splitParagraph 不改；渲染段在 cls 数组追加类型类：mat-thesis / mat-evidence / mat-quote / mat-measure；
- 已有 materialType 时不再拼 hl-{color}（类型色优先；用户改色仍存 color 字段，取消素材标记后恢复）；
- 悬停徽标：标记元素加 data-mat="论点"，CSS ::after { content: attr(data-mat) } 悬停显示——伪元素不产生文本节点，**不影响偏移计算与选中**；
- 金句卡片（quote）悬停额外显示 ★ 背记入口（点击切换 memorized）。

#### ③ 标注管理菜单（点击正文标注）：标记为素材 / 取消

在现有「加笔记 / 删除高亮…」按钮区新增：

    [标记为素材 ▾]  论点 | 论据·理论 | 金句 | 对策
    [取消素材标记]        ← 仅当已有 materialType 时显示

- 把已有高亮/划线转成素材（update 补 materialType），或撤销（删除 materialType 字段，恢复原色）；
- 菜单标签行显示当前素材类型徽标。

#### ④ 右侧栏（article-tools）：学习状态 + 拆解入口

在「阅读设置 / 字体 / 主题 / 收藏 / 显示标注」下方新增一节：

    申论拆解
    [未学 ▾] [★★☆]            ← 学习状态分段控件 + 掌握度星
    [打开拆解面板 →]
    已标记素材：论 2 · 据 1 · 句 3 · 策 1

- 学习状态：new/learning/mastered 三段按钮；
- 掌握度：1–3 星点击切换；
- 「打开拆解面板」：桌面端右侧抽屉，移动端底部面板。

| src/pages/LibraryPage.tsx | 学习状态徽标 + 素材数 |
| src/pages/HomePage.tsx | 继续阅读卡状态（轻量） |
| src/styles/reading.css | mat-* 四类色、悬停徽标、工具栏素材行、拆解面板抽屉 |
| src/styles/notes.css | 类型徽标、背记星、筛选控件 |
| src/components/layout/Nav.tsx | 不改（无新路由） |

技术要点：

1. **渲染不破坏偏移**：素材徽标用 ::after 伪元素 + attr()，不新增 DOM 文本节点；点击/选中行为与现有标注一致（data-ann-ids + showAnnActions 已就绪）。
2. **类型色优先**：cls 拼装时 materialType ? 'mat-'+t : 'hl-'+color；取消素材标记后恢复存储色。
3. **素材计数**：页面层 useMemo 过滤 annotationStore，不落 store。
4. **拆解面板定位正文**：复用 paragraphStarts + 段落换算（同 noteParaIndex 实现）。
5. **导入兼容**：旧导出文件无 shenlun 字段 → 静默跳过；旧摘录无 materialType → 视为未标记素材，全部路径兼容。

## 十、风险与决策点

| # | 决策点 | 结论（v1） | 理由 |
|---|---|---|---|
| D1 | 素材卡片与摘录是否同生命周期 | **是**（删除摘录=删素材） | 语义一致、零新实体；后续可加「仅删视觉标注」选项 |
| D2 | 是否支持「自填素材卡片」（无偏移） | **否** | 保持 Annotation 必有 start/end 的不变式；手动内容走 ArticleStudy 字段；后续可扩展偏移可选 |
| D3 | 拆解面板形态 | 阅读页内抽屉（桌面）/ 底部面板（移动） | 不打断阅读上下文；独立 /study 页列为后续可选 |
| D4 | 素材类型是否可扩展 | 固定 4 类 | 与目标清单一致；常量集中便于扩展。**2026-08-30 经决策 D15 修订为 5 类（新增 pattern 句式）** |
| D5 | 学习状态与掌握度并存 | 状态（粗粒度）+ 星（细粒度） | 状态服务列表扫描，星级服务个人评估 |
| D6 | 背记复习模式 | Phase 3 可选子任务 | 先保证「标记+筛选」闭环 |
| D7 | 素材库独立页面 | v1 不做，摘录页加筛选 | 降复杂度；数据模型已支持日后升级 /materials |
| D8 | 真题 / 规范词是否纳入本期 | **否**，列为后续阶段 | 素材（§1.1 ②③）已盘点确认存在且结构清晰；先保证 517 篇时评的拆解闭环，再扩展真题阅读（需 PDF 解析）与规范词库 |

主要风险：

- **摘录页筛选维度增多导致拥挤** → 素材类型筛选放第二行紧凑 chip 组，与主题筛选同风格；
- **素材色与用户自选高亮色冲突** → 类型色优先 + 徽标兜底，取消标记恢复原色；
- **Phase 2 抽屉在窄屏的可用性** → 复用底部面板模式（与选择工具栏一致）。
