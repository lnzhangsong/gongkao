# 决策：规范词/试卷写路径仅保留本地，生产永久只读

> 决策日期：2026-09-13。状态：**已定，非临时方案**。
> 关联代码：`scripts/api-server.mjs`（唯一写入口）、`src/lib/capabilities.ts`（能力探测）、`src/hooks/useLocalWrite.ts`（前端 gate）、`src/pages/TermsPage.tsx` / `ReadingPage.tsx` / `ExamPreviewPage.tsx`（按能力显隐）。

## 一、背景

规范词（guifan_terms 表）与申论试卷（papers/materials/questions 表）的增删改接口**只存在于本地开发服务器** `scripts/api-server.mjs`；生产（Vercel Functions）对这两个资源只有 GET，Supabase 侧也没有对应表（`sql/` 与 cloudSync 均未涉及）。

这带来过一个真实缺陷：前端此前无条件渲染写入口，生产用户在阅读页划词会看到「存规范词」按钮，点了必然失败——其中 TermsPage 还因生产响应缺 `id` 出现过编辑态全卡片串键、React 重复 key 的事故（2026-09-13 修复，见 `api/terms.ts` 与 `api/api-server.test.ts` 的 parity 断言）。

## 二、考虑过的三个方案

| 方案 | 内容 | 结论 |
|---|---|---|
| 1. 隐藏写 UI | 各页面自判环境隐藏按钮 | 被方案 2 覆盖；各页自判已实测漏 gate（第一版只盖了 1/3） |
| 2. 能力探测 | `GET /api/capabilities` → `{write:true}`，前端运行时按结果显隐 | ✅ **已落地**，兜住「显示但点了必失败」的坏状态 |
| 3. 生产写路径 | Supabase 建 terms/exams 表 + RLS + 云同步语义 | ❌ **不采纳**（本决策） |

## 三、决策

**线上（生产环境）去掉「存规范词」等一切规范词/试卷写功能，只保留本地。**即方案 3 永久搁置，不是「等有空再做」：

1. **生产 = 只读**。规范词库在生产上是官方维护的公共内容（`import-guifanci.mjs` 全量重建入库）；试卷在生产上同样只读。用户数据走既有的 Supabase 同步体系（笔记/标注/作答），不新增用户生成内容类别。
2. **本地 = 可写**。`scripts/api-server.mjs` 是唯一写入口，供录入与维护（真题编辑、规范词增删改、划词存词），写完随 `articles.db` 入 git。
3. **前端按能力探测显隐**，不按构建模式判断。判定收口在 `useLocalWrite()` 一个 hook：本地 server 在线 → 显示写入口；生产（探测 404）→ 不渲染按钮，而不是渲染了让用户点了报错。

## 四、为什么不做方案 3

- 「存规范词」要真正上生产，需要：Supabase 建表 + RLS（`user_id = auth.uid()`）、私有词与公共词库的关系（另表还是挂 user_id）、IndexedDB 缓存与云端的冲突/离线语义、`addTerm` 按登录态分流——一套完整的新用户数据类别，成本远超该功能的权重。
- 该功能的价值场景（划词积累 → 词库复习）在本地开发/自托管场景已完整可用；公共词库本身已覆盖生产用户的主要需求。

## 五、边界与注意

- **新增写接口必须同步加 gate**：以后任何页面想暴露本地专属写操作，必须走 `useLocalWrite()`，禁止自判 `import.meta.env.DEV`（那是构建模式不是写能力，`vp preview` 场景两者相反）。
- **parity 测试锁形状**：`api/api-server.test.ts` 对全部 GET 端点断言「本地 HTTP ≡ 直调 handler」，且专门锁 terms 带 `id`——本地/生产形状漂移会在测试红。
- **能力探测协议**：`/api/capabilities` 仅本地 server 提供，且回答「**该请求方**能否写」——设了 `WRITE_TOKEN` 时无令牌即 `{write:false}`，探测带 `x-write-token`（值存 `localStorage readbook:write-token`，设置方法见 `.env.example`）；生产 Vercel 无此 Function，404 即只读，无需额外配置。探测失败（网络/未就绪）不缓存，hook 层 1s/3s 各重试一次，`dev:all` 竞态下页面可自愈。
