## 一、P0 · 「开始阅读」入口固化（本次新增）

**现状**：首页入场卡永远打开同一篇文章。
`src/pages/HomePage.tsx`：

```ts
const featured = useMemo(() => articles.find((a) => a.featured) ?? articles[0], [articles])
```

`featured` 标记只有一篇（或落到 `articles[0]`），无论读到哪、哪天打开，「开始阅读」都指向它。

**方案对比**

| 方案 | 规则 | 优点 | 缺点 |
|---|---|---|---|
| A 顺序推进 | 取第一篇未开始/未读完的文章 | 符合「年编逐篇啃」的心智，进度可预期 | 每天打开是同一篇直到读完 |
| B 每日轮换 | 按日期哈希从未读池选一篇，当天固定 | 新鲜感 | 与年编顺序无关，积累感弱 |
| **C 混合（推荐）** | ① 有进行中的（`continueList[0]`）→ 继续阅读；② 否则取第一篇未读；③ 全部读完 → 从已读中随机复习 | 兼容三种使用状态，逻辑自然 | 实现略多（但 continueList 已有现成计算） |

**验收标准**

- [ ] 连续两天打开首页，未产生任何阅读进度时，入场指向不变化（同一天内稳定）
- [ ] 读过 3 篇后，入场指向第 4 篇未读（而非 featured）
- [ ] 读到一半的文章出现在入场位时显示「继续阅读」语义
- [ ] 首页 eyebrow 的假数据 `NO. 024` 同步替换为真实文章编号 / 当日日期

## 三、P1 · 骨架屏视觉升级（已点名，遗留）

**问题**：灰色渐变圆角条是通用组件库风格，与「纸面编辑排版」气质不符。

**改造要点**（`reading.css .skeleton-line` / `library.css .skeleton-row`）

- 配色：中性灰 → `color-mix(in srgb, var(--ink) 6~10%, transparent)` 的「淡墨」效果，五套主题（含夜读/墨夜）自动适配
- 形状：去圆角（设计语言为直角）、高度对齐正文字号节奏（`--reader-font-size` × 行高）
- 结构：每个段落占位 = 首行缩进两格 + 2~3 行 + 末行收窄的自然参差，段间距与正文一致
- 动画：保留 shimmer 但放缓（~2s），`html.reduced-motion` 下静默（现有全局规则已覆盖）
- 文库行架同步改造：编号列 + 标题行 + 元信息的组合占位

## 七、追加批次（2026-08-25 下午）——已修复

### 1. 主题文字对比度（「文字和背景太近看不清」）

**问题**：accent 色小字（tag / 标签 / hover）直接压在纸底上，实测对比度 paper **2.90**、blue **3.05**、violet **2.49**（AA 要求 ≥4.5）；入场卡次要标签 `color-mix(yellow 62%, black)` 在 blue/violet 的 dark 底上仅 **~3.9**。

**修复**：

- 新增 `--accent-text` 令牌（`tokens.css`）：accent 的可读文本变体，小字专用

  | 主题 | accent（装饰/大标题保留） | accent-text（小字） | 实测对比 |
  |---|---|---|---|
  | paper | `#e96448` | `#a9431f` | 5.27 |
  | blue | `#667ff0` | `#4557c4` | 5.24 |
  | violet | `#aa7bff` | `#744bc2` | 4.93 |
  | night | `#d7f267` | 同 accent | 12.8 |
  | graphite | `#d9ff5a` | 同 accent | 16.5 |

- 全站 `color: var(--accent)` 的小字场景统一切换为 `--accent-text`（tag、topic、hover/active 态等 50+ 处）；**4 处大标题 span 保留亮色**（首页/文库/设置大标题、loading 大字——大字号 AA 阈值 3:1，且属品牌识别色）
- 入场卡次要标签混黑比例 62% → **70%**，五主题全部 ≥4.8
- `.entry strong`「开始阅读」：黑体 600 负字距 → 衬线 500 正字距，与全站标题排版统一；`.continue-bar` 圆角 14px → 2px

### 2. 首页「开始阅读」板块设计一致性

- `.entry strong`「开始阅读」：黑体 600 负字距 → **衬线 500 + 0.02em 正字距**，与全站标题排版语言统一（原为原型遗留，与整体衬线气质脱节）
- `.continue-bar` 圆角 14px → **2px**：全站唯一的圆角块，与 `.item` 等直角语言对齐

**验证**：五主题首页截图逐项目检（violet / graphite 已确认标签清晰、卡片排版统一）；构建通过。

### 3. 暗色主题文字色阶重调（「暗色下对比还是不太行」）

全量审计五主题 × 11 组文字/背景对（正文 / muted / tag / 入场卡标签 / picks 卡片 / 反色 pill / 划选），发现并修复：

| 问题 | 修复 |
|---|---|
| 首页 picks 卡第 2 张：暗色下 `--yellow`=亮 lime 做卡片底，配浅色文字 ≈ **1.06:1** | 新增 `--pick-a/-b` 令牌：暗色主题用 `color-mix` 向 paper 混合的低饱和暗面板（lime 混 14%，保证卡上 muted 小字 ≥4.5）；浅色主题回退原 blue/yellow |
| `::selection` 划选文字：暗色下 lime 底 + 浅色 ink ≈ **1.06:1** | 文字改用 `--body-bg`（暗色主题为近黑；浅色主题行为不变） |
| muted 次要文字在暗底上仅 ~6.5，小字多时发灰 | night `#a2a89e→#b3b9ad`（7.98）、graphite `#9297a3→#a6acb8`（8.28）；ink 同步微调 |
| 浅色主题卡片上 muted 标签 3.1~4.4 不达标 | `.item small` 改为 `color-mix(ink 80%, 纸色)` 随卡色自适应（实测 4.69~9.15）；violet muted 加深至 `#655e78` |
| 文库 `featured-main` / `collection` 残留 14px 圆角 | → 2px，与全站直角语言一致 |

**审计结果**：五主题全部文字/背景对 ≥4.5:1（AA），构建通过，night / graphite 截图目检通过。

### 6. 暗色卡片黑字压暗底（2026-08-26）——本次

**根因**：首页底部 `.item` 与文库 `.article-row` 是 `<button>` 元素，`src/styles/base.css` 的 `button { font-family: inherit; }` 未声明 `color`，浏览器 UA 默认 `color: buttontext（纯黑）` 覆盖继承；浅色主题下黑字压浅底可读，暗色主题下黑字压深色卡底（`--paper/#20221f` / `--pick-a/#2c342d`）≈ **1.06:1** 几乎看不见（截图已确认）。

**修复**：

- `home.css .item` 显式 `color: var(--ink)`；`library.css .article-row` 同理
- `base.css button` 补 `color: inherit` 全局兜底（显式色如 `.ghost`、`.page-btn` 仍由各自规则覆盖）

**验证**：`getComputedStyle(h4).color` 在 night 主题下由 `rgb(0,0,0)` → `rgb(244,242,234)`（`--ink`），构建通过，端到端 93/93，`btm-night.png` 卡片标题恢复为浅色。
