### M1 修订十一点摘要（2026-09-03~05 用户反馈逐轮）

1. 静态方法论卡 → AI 针对题目推导（两轮否决静态卡）；
2. 解析面板右侧悬浮 → 底部上下分栏（原文不遮挡、桌面可滚动）；
3. 面板拖拽调高（把手 + localStorage 记忆）+ 全屏按钮（90vh）；
4. 要点卡改教方法三步链：定位 → 材料 → 加工判断 → 要点句；
5. 「加工方式怎么选」六类口诀速查；
6. 标注内联化：`「辅助〈背景铺垫〉：…」` 句后不换行，高亮透明底+等级色下划线（useless 删除线），无气泡无手型；
7. 标注显示改右栏「行文思路」常驻开关（记忆状态，弃抽屉驱动）；
8. 保存交互：顶部「编辑/完成编辑」就地保存，删底部按钮；AI 草稿即进编辑态；
9. 圆圈光标下 `cursor:none !important` 压掉原生手型；
10. 关闭解析面板自动带回题目抽屉；
11. 代码拆分 + 死 CSS 清理（同上表末行）。
