## 一、P0 · 「开始阅读」入口固化（本次新增）

**现状**：首页入场卡永远打开同一篇文章。
`src/pages/HomePage.tsx`：

```ts
const featured = useMemo(() => articles.find((a) => a.featured) ?? articles[0], [articles])
```

`featured` 标记只有一篇（或落到 `articles[0]`），无论读到哪、哪天打开，「开始阅读」都指向它。

**方案对比**

| 方案 | 规则 | 优点 | 缺点 |
|---|---|---|---|
| A 顺序推进 | 取第一篇未开始/未读完的文章 | 符合「年编逐篇啃」的心智，进度可预期 | 每天打开是同一篇直到读完 |
| B 每日轮换 | 按日期哈希从未读池选一篇，当天固定 | 新鲜感 | 与年编顺序无关，积累感弱 |
| **C 混合（推荐）** | ① 有进行中的（`continueList[0]`）→ 继续阅读；② 否则取第一篇未读；③ 全部读完 → 从已读中随机复习 | 兼容三种使用状态，逻辑自然 | 实现略多（但 continueList 已有现成计算） |

**验收标准**

- [x] 连续两天打开首页，未产生任何阅读进度时，入场指向不变化（同一天内稳定）
- [x] 读过 3 篇后，入场指向第 4 篇未读（而非 featured）
- [x] 读到一半的文章出现在入场位时显示「继续阅读」语义
- [x] 首页 eyebrow 的假数据 `NO. 024` 同步替换为真实文章编号 / 当日日期

### 1. 主题文字对比度（「文字和背景太近看不清」）

**问题**：accent 色小字（tag / 标签 / hover）直接压在纸底上，实测对比度 paper **2.90**、blue **3.05**、violet **2.49**（AA 要求 ≥4.5）；入场卡次要标签 `color-mix(yellow 62%, black)` 在 blue/violet 的 dark 底上仅 **~3.9**。

**修复**：

- 新增 `--accent-text` 令牌（`tokens.css`）：accent 的可读文本变体，小字专用

  | 主题 | accent（装饰/大标题保留） | accent-text（小字） | 实测对比 |
  |---|---|---|---|
  | paper | `#e96448` | `#a9431f` | 5.27 |
  | blue | `#667ff0` | `#4557c4` | 5.24 |
  | violet | `#aa7bff` | `#744bc2` | 4.93 |
  | night | `#d7f267` | 同 accent | 12.8 |
  | graphite | `#d9ff5a` | 同 accent | 16.5 |

- 全站 `color: var(--accent)` 的小字场景统一切换为 `--accent-text`（tag、topic、hover/active 态等 50+ 处）；**4 处大标题 span 保留亮色**（首页/文库/设置大标题、loading 大字——大字号 AA 阈值 3:1，且属品牌识别色）
